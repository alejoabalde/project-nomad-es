# Acerca de Project NOMAD

Project NOMAD («NOMAD», para abreviar) es un proyecto que inició en 2025 Chris Sherwood, de [Crosstalk Solutions, LLC](https://crosstalksolutions.com). El objetivo no es crear otra utilidad más para guardar recursos sin conexión, sino permitir que cada persona tenga su propia «computadora de supervivencia» definitiva. El nombre empezó como un acrónimo en inglés, Node for Offline Maps, Archives, and Data (nodo para mapas, archivos y datos sin conexión), pero hoy simplemente le decimos NOMAD.

Mientras que muchas computadoras de supervivencia sin conexión similares están pensadas para funcionar en equipos mínimos y livianos, Project NOMAD es todo lo contrario. Para instalar y usar las herramientas de IA disponibles, recomendamos especialmente un equipo potente con GPU para sacarle el máximo provecho. Consulta la [guía de hardware](https://www.projectnomad.us/hardware) (en inglés) para ver recomendaciones detalladas en tres rangos de precio.

Desde su primera versión, NOMAD sumó un chat de IA integrado con una base de conocimiento para respuestas que tienen en cuenta tus documentos, un benchmark del sistema con tabla de la comunidad, colecciones de contenido seleccionadas con distintos niveles y un asistente de Configuración rápida para que los usuarios nuevos empiecen enseguida.

Project NOMAD es de código abierto y se publica bajo la [Licencia Apache 2.0](https://github.com/Crosstalk-Solutions/project-nomad/blob/main/LICENSE).
